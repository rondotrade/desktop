## IBKR 使用说明

- IBKR 对登录 IP 和设备的校验较严，一次只能登录一个账号。
- 如果已经登录完成，但 app 仍然没有完成登录：先到 IBKR 官网登录一次，完成首次登录验证（邮箱验证），之后再回到 app 登录即可。

### 创建第二个使用者

一个使用者同一时间只能在一台设备上登录，手机端和 app 会互相挤掉。给同一个账户再建一个使用者，手机端和 app 各用一个就不冲突。资产还是同一份，只是多了一个登录入口。

在 IBKR 官网操作：设置 → 使用者&访问权限 → 添加使用者。

**1. 填写使用者信息**

用户名可以带个 `-rondo` 之类的后缀，方便区分。「该使用者是否为安全官员」选「否」；「这是第一账户持有人的另一个使用者吗」选「是」，选「是」才是同一个账户持有人名下的使用者。

![添加使用者](screenshots/ibkr-add-user-1.png)

**2. 完成提交后的两件待办**

提交完还不能直接用，页面上列了两件必须做完的事：在待定事项页面提交交易者授权证明；新使用者用刚才设置的用户名和密码登录一次网页端，确认邮箱并修改密码。

![请求已提交](screenshots/ibkr-add-user-2.png)

**3. 签交易者授权证明**

核对账户持有人、被授权交易者、账户号码和用户名，填入签名后点「本人同意」。

![交易者授权证明](screenshots/ibkr-add-user-3.png)

两件待办都完成后，新使用者就能在 app 里登录，原来的使用者留给手机端。
